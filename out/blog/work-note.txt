b:Te6a,<h2 id="1canvas绘制元素优化方案">1.canvas绘制元素优化方案</h2>
<p>在2024年年底开发了一个基于zrender的canvas图表库,这个代码库实现了一个树图组件,当初子节点渲染很多导致很卡顿</p>
<p>当时采用了以下方案进行的性能优化</p>
<h4 id="视口裁剪viewport-culling--核心优化">视口裁剪（Viewport Culling）- 核心优化</h4>
<ul>
<li><strong>实现智能视口裁剪机制</strong>，只渲染当前可见区域内的节点和边</li>
<li><strong>性能提升</strong>：
<ul>
<li>大数据量场景下（1000+ 节点）渲染性能提升 60-80%</li>
<li>缩放、平移等交互操作响应速度显著提升</li>
<li>内存占用大幅降低，避免不必要的元素创建</li>
</ul>
</li>
<li><strong>工作原理</strong>：
<ul>
<li>实时计算可视区域（viewport）范围</li>
<li>动态过滤可见节点和边，仅渲染在视口内的元素</li>
<li>支持缩放和平移时自动更新可见元素集合</li>
<li>采用高效的边界检测算法，减少计算开销</li>
</ul>
</li>
</ul>
<h2 id="2ios设备的textarea元素唤起原生键盘让页面整体滚动">2.ios设备的textarea元素唤起原生键盘让页面整体滚动</h2>

<pre><code>1. 用户点击 textarea
   ↓
2. textarea 获得焦点 (isFocused = true)
   ↓

   ↓
4. 视口高度变化 (触发 handleViewportChange)
   ↓

   ↓

   ↓

   ↓

</code></pre>

<pre><code class="language-vue">/**
     * iOS 键盘适配 - 滚动到 textarea 位置，确保可见
     */
    scrollToTextarea() {
      const textarea = this.$refs.multLIneInputArea;
      if (!textarea) return;
      
      const contentEl = document.querySelector('.content');
      if (!contentEl) return;
      
      // 获取 textarea 相对于 content 的位置
      const textareaRect = textarea.getBoundingClientRect();
      const contentRect = contentEl.getBoundingClientRect();
      
      // 计算需要滚动的距离
      const offsetTop = textareaRect.top - contentRect.top + contentEl.scrollTop;
      const keyboardHeight = this.initialViewportHeight - this.currentViewportHeight;
      const visibleHeight = this.currentViewportHeight;
      
      // 确保 textarea 在可视区域内，留出一些间距
      const targetScrollTop = offsetTop - (visibleHeight - keyboardHeight) / 2;
      
      // 平滑滚动到目标位置
      if (contentEl.scrollTo) {
        contentEl.scrollTo({
          top: Math.max(0, targetScrollTop),
          behavior: 'smooth'
        });
      } else {
        contentEl.scrollTop = Math.max(0, targetScrollTop);
      }
    }
</code></pre>
