<h2 id="一申请远程服务器">一、申请远程服务器</h2>
<p>远程服务器现在市面上有很多供应商提供很多服务器,比如阿里、腾讯,我本次就购买了阿里的服务器《轻量应用服务器》</p>
<p>一系列操作之后就可以进入平台,我选择的都是默认的配置,然后点击<code>远程连接</code>,就可以进入到阿里提供的服务器上</p>
<p><img src="/images/blog/build-web/1.png" alt="1"></p>
<p>阿里远程提供了一个简易版的ai助手,如果一时想不起linux命令就可以问问他,还是有点方便的</p>
<p><img src="/images/blog/build-web/2.png" alt="2"></p>
<h2 id="二远程服务器环境搭建">二、远程服务器环境搭建</h2>
<ul>
<li>接下来就是常规的环境配置了,包含node、git、nginx环境配置:</li>
</ul>
<h3 id="1yum--y-install-git">1.yum -y install git</h3>
<h3 id="2yum-install-nodejs">2.yum install nodejs</h3>
<ul>
<li>
<p>这里也可以使用wget下载:
wget <a href="https://nodejs.org/dist/v16.14.0/node-v16.14.0-linux-x64.tar.xz">https://nodejs.org/dist/v16.14.0/node-v16.14.0-linux-x64.tar.xz</a></p>
</li>
<li>
<p>解压文件的 bin 目录底下包含了 node、npm 等命令
tar xf node-v16.14.0-linux-x64.tar.xz</p>
</li>
<li>
<p>把nodejs bin目录添加到环境变量</p>
</li>
</ul>
<pre><code class="language-md">1、备份老文件，防止改错弄坏服务器
cp /etc/profile /etc/profile_old

2、修改环境变量
vi /etc/profile     在文件尾部添加 export PATH=$PATH:/opt/node-v16.14.0-linux-x64/bin

3、刷新环境变量
source /etc/profile

node -v      输出版本号 16.14.0 即为配置成功
</code></pre>
<p>由于我的项目是大于18的所以我配置了20的环境变量</p>
<p><img src="/images/blog/build-web/3.png" alt="3"></p>
<h3 id="3sudo-yum--y-install-nginx">3.sudo yum -y install nginx</h3>
<ul>
<li>
<p>安装好了可以访问nginx配置文件使用：vim /etc/nginx/nginx.conf</p>
</li>
<li>
<p>具体环境变量如何配置,请参考我的nginx那篇文章的讲解即可</p>
</li>
</ul>
<h4 id="如果无法使用yum安装nginx可以考虑使用">如果无法使用yum安装nginx可以考虑使用</h4>
<ul>
<li>dnf -y install <a href="http://nginx.org/packages/centos/8/x86">http://nginx.org/packages/centos/8/x86</a> _64/RPMS/nginx-1.18.0-1.el8.ngx.x86 _64.rpm</li>
</ul>
