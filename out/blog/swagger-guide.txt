<h2 id="1-安装-swagger-工具">1. 安装 Swagger 工具</h2>
<h3 id="方法一手动安装">方法一：手动安装</h3>
<pre><code class="language-bash">go install github.com/swaggo/swag/cmd/swag@latest

<p>项目已经集成了自动安装功能，只需要运行：</p>

</code></pre>

</code></pre>
<h2 id="3-配置-swagger">3. 配置 Swagger</h2>
<h3 id="31-在-maingo-中添加配置">3.1 在 main.go 中添加配置</h3>
<p>在 <code>cmd/server/main.go</code> 文件中添加以下内容：</p>
<pre><code class="language-go">import (
    // ... 其他导入
    _ "front-page/docs" // 导入生成的 Swagger 文档
    swaggerFiles "github.com/swaggo/files"
    ginSwagger "github.com/swaggo/gin-swagger"
)

// @title           Front Page API
// @version         1.0
// @description     Front Page 项目的 API 文档
// @termsOfService  http://swagger.io/terms/

// @contact.name   API Support
// @contact.url    http://www.swagger.io/support
// @contact.email  support@swagger.io

// @license.name  Apache 2.0
// @license.url   http://www.apache.org/licenses/LICENSE-2.0.html

// @host      localhost:8080
// @BasePath  /api/v1

func main() {
    // ... 其他代码
    
    // 添加 Swagger 路由
    router.GET("/swagger/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))
    
    // ... 其他代码
}
</code></pre>
<h3 id="32-在-api-处理函数中添加注释">3.2 在 API 处理函数中添加注释</h3>
<p>在 API 处理函数上添加 Swagger 注释，例如：</p>
<pre><code class="language-go">// @Summary      获取所有待办事项
// @Description  返回所有待办事项的列表
// @Tags         todos
// @Accept       json
// @Produce      json
// @Success      200  {array}   Todo
// @Router       /todos [get]
func listTodos(c *gin.Context) {
    // ... 函数实现
}
</code></pre>
<h2 id="4-生成文档">4. 生成文档</h2>
<h3 id="方法一使用-makefile推荐">方法一：使用 Makefile（推荐）</h3>
<pre><code class="language-bash">make swagger
</code></pre>
<h3 id="方法二直接使用-swag-命令">方法二：直接使用 swag 命令</h3>
<pre><code class="language-bash">swag init -g cmd/server/main.go
</code></pre>
<h2 id="5-启动服务">5. 启动服务</h2>
<h3 id="方法一使用-makefile推荐-1">方法一：使用 Makefile（推荐）</h3>
<pre><code class="language-bash">make run-with-docs
</code></pre>
<h3 id="方法二直接运行">方法二：直接运行</h3>
<pre><code class="language-bash">go run cmd/server/main.go
</code></pre>
<h2 id="6-访问-swagger-ui">6. 访问 Swagger UI</h2>
<p>启动服务后，可以通过以下地址访问 Swagger UI：</p>
<pre><code>http://localhost:8080/swagger/index.html
</code></pre>
<h2 id="7-常用命令说明">7. 常用命令说明</h2>
<ul>
<li><code>make swagger</code> - 生成 Swagger 文档</li>
<li><code>make run</code> - 运行服务器</li>
<li><code>make run-with-docs</code> - 生成文档并运行服务器</li>
<li><code>make clean</code> - 清理编译文件</li>
</ul>
<h2 id="8-注意事项">8. 注意事项</h2>
<ol>
<li>修改 API 后需要重新生成文档</li>
<li>确保所有 API 处理函数都有正确的 Swagger 注释</li>
<li>文档生成后会自动创建 <code>docs</code> 目录</li>
<li>可以通过 Swagger UI 测试 API 接口</li>
</ol>

<ol>
