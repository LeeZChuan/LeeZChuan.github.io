很长一段时间，我都在想要不要重新开始写博客。

最后的答案是：**写**。原因很简单 —— 写作是最好的思考方式之一。当你把脑子里模糊的想法写成文字，你会发现很多之前认为清晰的逻辑其实存在漏洞。这个"漏洞发现机制"对我来说非常有价值。

## 为什么要写博客

有几个理由：

1. **整理思路** — 技术学习最好的方式是能用自己的话讲清楚
2. **记录成长** — 几年后回头看，能看到自己的变化
3. **分享与连接** — 也许某篇文章能帮助到有相同问题的人
4. **英文输入，中文输出** — 大量技术资料是英文的，用中文整理有助于消化

## 这个博客会写什么

主要是技术内容：

- Web 开发技术（前端、后端、架构）
- 工具和工作流分享
- 开源项目的开发记录
- 偶尔一些非技术的思考

我不打算对发文频率做承诺，质量比数量重要。

## 技术选型

这个博客用 [Astro](https://astro.build) 构建。选择 Astro 的原因：

- 静态生成，性能极佳
- 支持 MDX，写作体验好
- 原生支持部分水合，可以在需要的地方加入交互
- 构建产物干净，没有多余的 JavaScript

主题设计受 [antfu.me](https://antfu.me) 启发，追求简洁。
